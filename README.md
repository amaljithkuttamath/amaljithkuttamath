### What I'm working on

**[trust-bench](https://github.com/amaljithkuttamath/trust-bench)** — an interpretability toolkit for Llama 3.1 8B. Probes SAE features, activations, and circuits. Three probes, statistical analysis, publication-quality viz, one CLI.

**[jlens-replication](https://github.com/amaljithkuttamath/jlens-replication)** — replicating Anthropic's Jacobian lens on small open-weight models with free compute (Kaggle T4×2, Colab, Lightning L4).

**[mlx-interp](https://github.com/amaljithkuttamath/mlx-interp)** — the first mech-interp library for Apple's MLX. Train BatchTopK and Matryoshka SAEs on Apple Silicon.

### Things I've found

- A single SAE feature (#10543) in Gemma 2 2B that fires on "and" across six languages. Zero false positives → [sae-explorer](https://github.com/amaljithkuttamath/sae-explorer)
- A phase transition at 0.7 sparsity while reproducing Anthropic's Toy Models of Superposition → [superposition-viz](https://github.com/amaljithkuttamath/superposition-viz)
- Whether scaling laws hold at toy scale (100K–10M params) → [scaling-laws](https://github.com/amaljithkuttamath/scaling-laws)
